# Calculator App

A responsive and interactive **Calculator** web application built using HTML5, CSS3, and Vanilla JavaScript to perform standard arithmetic calculations directly in the browser.

## 🚀 Live Demo
👉 **[View Live Calculator](https://manshu2003.github.io/CALCULATOR/)**

---

## ✨ Features
* **Basic Arithmetic Operations:** Supports addition (`+`), subtraction (`-`), multiplication (`×`), and division (`÷`).
* **Interactive Button Grid:** Responsive button layout with click handling and real-time display updates.
* **Clear & Reset Controls:** Quickly clear or reset the calculation screen for new inputs.

---

## 📂 Project Structure
* **`index.html`** – Defines the calculator display screen and button grid layout.
* **`style.css`** – Handles visual styling, button grid alignment, hover effects, and responsive layout.
* **`script.js`** – Implements button click event listeners, expression evaluation, and display logic.
