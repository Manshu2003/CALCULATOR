# Calculator App

A clean, modern, and interactive **Calculator** web application built using HTML5, CSS3, and Vanilla JavaScript. Designed with a centered card UI, dark slate number keys, and lime-green operator buttons, it supports multi-step arithmetic expressions directly in the browser.

## 🚀 Live Demo
👉 **[View Live Calculator](https://manshu2003.github.io/CALCULATOR/)**

---

## ✨ Features
* **Standard Arithmetic Operations:** Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
* **Parentheses & Decimal Support:** Evaluate grouped expressions using `(` and `)` along with decimal point (`.`) calculations.
* **Smart Clear Controls:**
  * **`AC` (All Clear):** Resets the entire display screen at once.
  * **`C` (Clear / Backspace):** Deletes the last entered character/digit.
* **Modern Circular Keypad UI:** Centered calculator layout with color-coded circular buttons and a high-contrast digital display screen.

---

## 📂 Project Structure
* **`index.html`** – Defines the calculator display screen and 20-button circular grid layout.
* **`style.css`** – Handles the centered card styling, color-coded circular buttons, grid alignment, and typography.
* **`script.js`** – Manages button click events, expression building, `AC`/`C` controls, and calculation evaluation.
